## Vertical privilege escalation

Vertical privilege escalation occurs when a user gains access to functionality or administrative actions that their account role is not permitted to use.

## Key Characteristics

- **Moving "Up" in Privilege**: A lower-privileged user (such as a standard user or unauthenticated guest) accesses features meant strictly for higher-privileged roles (such as an administrator or moderator).

- **Real-World Example**: A regular, non-administrative user discovers or accesses an admin endpoint (like /admin) and gains the ability to delete user accounts or change system settings.
