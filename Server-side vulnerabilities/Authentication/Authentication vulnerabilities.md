# Authentication Vulnerabilities

Authentication vulnerabilities occur when flaws in a website's login, password reset, or identity verification mechanisms allow an attacker to bypass authentication and impersonate legitimate users.

## Why Authentication Flaws Are Critical

- **Direct Compromise**: Breaking authentication gives attackers immediate access to sensitive user data and privileged functionality.

- **Expanded Attack Surface**: Once authenticated as a valid user or administrator, an attacker can reach internal features that are completely hidden from unauthenticated visitors, opening the door for further exploits.
